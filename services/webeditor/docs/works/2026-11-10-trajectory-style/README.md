# 2026-11-10 半透明轨迹点与连线

## 原因
用户要求轨迹点半透明、缩小半径，相邻点用相同颜色的细线连接。

## 做了什么
- 规格 §7.3/§9.1 就地修订。配置、Gateway 内置默认、logic.ts 回退半径由 0.02 米改为 0.01 米，共享类型注释同步。
- renderer.ts 保留各轨迹实例球，新增其子节点 THREE.Line，以采样顺序连接相邻点；点与线同色、透明度 0.5、关闭深度写入，线宽 1 像素。
- 连线随原轨迹层显隐与 dispose；复用时更新坐标与 drawRange，单点无连线，空路径移除旧层。两条轨迹/不同叶子臂分别建层，不跨层连接。
- 复用既有 Three.js，不增加依赖、配置键或 feature 键，不改轨迹数据与采样密度，不操作用户服务。
