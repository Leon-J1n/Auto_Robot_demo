## 原因与做了什么（PLAN_STATE 备注）

FIX-2026-10-13 维护卡第 ③ 张：选中相机时只剩视锥，删掉 `addCamera()` 里的 `ConeGeometry(0.12, 0.3, 12)` 线框标记（决议 Q71，规格 §4.4 排除图层清单随之补一句）。为什么删它是安全的：圆锥与视锥线都只挂 `userData.cameraMarker`，而 `isEditorOnly()`（Q50 世界盒过滤）、`hideOverlays()`（§4.4 拍照排除）与点选时的 `hits.find` 过滤读的都是这个标记而不是几何类型；圆锥是纯装饰，没有任何查询读它，`grep -rn ConeGeometry editor/src tools/` 现为零命中。留下的硬约束已钉进测试：视锥线必须继续带 `cameraMarker`，否则它会重新撑爆 `worldAabb`（坑 20 的原始症状）并出现在 `/captureScene` 的图里 —— `renderer.test.ts` 的相机用例因此补强为"带 `cameraMarker` 的子节点恰好一个"。真机：载入 `scene?id=1` 后树里选 `WristCameraD435i #4`，视口只剩一领青色视锥、顶点在相机处开口朝向桌面。验证同第 ② 张（vitest 260 例、build、smoke 8 项）。
