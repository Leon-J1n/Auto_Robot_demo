# 2026-11-09 启动时自动设置 OLS 地址

## 原因
用户要求双击启动时使用本机当前 IP 访问 8000 端口的 OLS，并避免频繁改写常量配置。

## 做了什么
规格 §11.6 就地补充启动约定。BAT 转交轻量 Python 启动器，复用现有 Python 运行环境、临时配置与网关 --config 入口。默认路由选择本机 IPv4，覆盖 library_server_url，保留其他配置和参数，退出清理临时文件。发布清单补入启动器，无新增依赖、协议或配置字段。不改网关及 start-dev.ps1，不重启用户服务。

## 验证
启动器 3 项、发布包 10 项测试通过，覆盖地址选择、不可用地址拒绝、源文件逐字节不变、配置保留、参数转发、退出码及异常清理；负控制撤销地址覆盖后仅配置覆盖测试失败，随后按字节恢复。真实网络地址探测及 --help 启动验证通过且未启动服务。网关路由 12/13 通过：默认配置一致性用例失败，原因为仓库 urdf_bounding_box_per_link=false 与内置 true 不同；以 git show HEAD:local_gateway.py 加载基线复跑同为 12/13，确认是已有差异，未改动用户配置。
