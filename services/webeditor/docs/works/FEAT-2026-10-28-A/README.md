### FEAT-2026-10-28-A —— 第九类组件 `LocalAxes`：把物体自己的本地坐标系画进视口（**Q130**；口径与实装同一张卡；依赖 M1-1、M1-4、M6-3、Q105/Q106、Q119）

- **起因（用户原话，两段）**：「我现在要添加一个新组件，这个组件的功能是，当某个物体具有该组件时，显示其本地坐标系的坐标轴。先设计这个组件需要的参数，然后更新docs/场景文件描述.md等相关的文档。最后给我一个新组件的例子。」定稿后接一句「开始实现，实现完成后在本地提交」——**只做本地提交，不推送**。六个取舍记在需求规格 §13.43 的 Q130 行（组件而非勾选框、常显而非选中才显示、长度不做 `scale` 补偿、字段只有三个且全部可选、fail-closed 但不补常量、以一面身份标志进编辑层）。
- **口径轮先落文档**：`docs/场景文件描述.md` 新增 §4.9（字段表 + 九条取值规则 + 两个例子 + 落点），§3 的识别数由八类改九类、§4 表下加注；本文 §3 组件定义添一行、§4.4 排除清单就地添一项、§9.3 添 `viewport.localAxes`（84 → **85 键**）、§12.26 先立判据、§13.43 落决议。

- **两处口径就地改口（实现读文档读出了矛盾，按文档的上级约定定）**：**① `colors` 那一行**原写「整体不是对象、**缺某个键**、某个色值非法 → 只有那一轴回到默认色**并告警**」，与同文 §3「字段缺失按默认值回退、**不报错**」相冲，且本节例子一（只写 `x`/`z`）自己就会打两条告警 —— 实现按 §3：键缺失静默回默认，只有**非法值**与 `colors` 整体不是对象才告警，那一行与本文 §3 组件定义那行都已改写。**② §12.26 ① 那句「`logic.ts` 不新增判据函数」**被 `localAxesRig()` 违反（它不是门控判据，是数值解析，与 `cameraRig()` 同族）—— 句子收窄成「不新增**门控**判据函数」，并写明新增的那份是什么、为什么两头不会各算一套。
- **一处连带（灯标签抽出 `textSprite()`）**：§4.5 的 `lightLabel()` 变成 `textSprite()` 外面包那一句 `scale.set(1.8, 0.28, 1)`，轴标签共用这条 canvas→Sprite 文字通路、但尺寸随 `length`（`rig.length × rig.length·40/256`）—— 0.1 m 的帧不能挂 1.8 m 的字。灯光一族的尺寸、位置与显隐判据一字未动，**既有 101 条渲染测试原样通过**。
