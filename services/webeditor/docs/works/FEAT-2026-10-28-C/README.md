## 任务卡原文

### FEAT-2026-10-28-C —— 本地坐标轴改由工具栏勾选框开关：`viewport.localAxes` 同日改名 `viewport.localAxesToggle`（**Q132**；口径与实装同一张卡；依赖 Q119、Q130、Q131）

- **起因（用户原话）**：「在工具栏添加一个勾选框，用于显示/不显示本地坐标轴，当勾选框勾选时，显示所有LocalAxes组件的坐标轴，否则不显示。然后viewport.localAxes（也许需要改个名字）的功能变为是否在工具栏显示这个勾选框」。三个岔路本轮问过、用户裁定：**键改名**为 `viewport.localAxesToggle`（"也许需要改个名字"落成一个说得出它现在管什么的名字）、**键关掉 ⇒ 勾选框消失且这一层也不画**（与 §4.8.6 第 6 条的包围盒同形，而不是"只收控件、轴照旧画"）、**勾选框默认不勾**。
- **口径与实装同一轮**：`docs/Web前端需求规格v2.md` 新增 **§4.8.8**（九条口径）、**§7.1** 那条勾选框（四条子项）、验收 **§12.28**（①单测／②负控制／③真浏览器／④接口面与回归）、决议 **§13.45**；就地改口 §3 组件定义那行的"显隐"、§4.4 那条 Q131 的同族清单（`viewport.localAxes` 从此族里出去）、§9.3 那一枚键、§12.26 ③ 的 A/D 两格、§13.43 的 Q130 行。`docs/场景文件描述.md` §4.9 就地改口两处（原"常显、视口工具栏不配勾选框"那一条整条重写为"两处开关 + 分工"，"落点"段随改名与宿主变化改口），并把末段对照升级为**三族开关**（世界原点轴与网格只有键；本节的轴有键与勾选框两处；两族互不影响）。README 的视口工具栏那段添一枚 **Show local axes**，紧挨卡 ㉚ 那枚 **Show every bounding box**、形状同族 —— 卡 ㊲／㊳ 没写 README（那两轮没有界面控件），本轮是这一族第一次进 README。
- **实装形态**：`logic.ts` 新增**门控判据**纯函数 `localAxesEnabled(features, checked)` = **键 && 勾选**，紧挨在 `boundingBoxesEnabled()` 下面，注释里写明"名字说它现在管什么"与**为什么不补常量**（Q119 的理由：这一层的默认外观就是不画，"宿主没来"与"没勾上"是同一张画面）。`main.ts` 四处：`state.localAxes: false`（视图态，与 `boxes` 同族）、工具栏那枚 `<label class="toolbar-check" data-feature="viewport.localAxesToggle">…<b>显示本地坐标轴</b>` 紧挨包围盒那枚、`renderLocalAxes()` 把**一个布尔**推给 setter、`toggleLocalAxes()` 收勾选框并照 §2.3 那句"点击必须有响应"答一句最短话术（`本地坐标轴已显示`／`已隐藏`）；`change` 委托添一条 `local-axes-toggle` 分支。`applyFeatureVisibility()` 里原来那行 `renderer.setLocalAxesEnabled(enabled("viewport.localAxes"))` 换成 `renderLocalAxes()` —— 键不再直接跟渲染器说话，但它仍是整层唯一的远程出口。`renderer.ts` 只改一个事实：类字段初值 `localAxesEnabled` 由 `true` 改成 `false`（默认画面上没有轴），`addLocalAxes()`／`isEditorOnly()`／`selectable()`／`markerNodes()`／`markerStates()`／重建签名／`logOverlayState()` **一字未动**，因为**渲染器收到的还是那一个布尔**，本轮没改它的契约。
