### FEAT-2026-10-15e —— 调用方样例 `examples/gateway_client_demo.py`（新卡；依赖 M3-1、M5-*、M7-*、Q84）

- **起因（用户原话）**：「请在 examples/ 中创建一个 python 文件，用于演示其他程序如何向 gateway 发送消息并获取返回结果。**接口列表中的所有接口都要有样例**。你可以使用 `F:\ObjectLibraryServer\data\scenes\6` 中的场景作为样例场景。但注意，**请不要通过路径引用这个文件**，你可以将其嵌入到例子里，**方便我后续将这个例子分发给其他人**。你可以假定样例程序运行前 gateway 已在 8080 端口启动，OLS 已在 8000 端口启动。」顺序按既定口径执行：文档（§5.9 指针 + Q84）→ 实现 → 测试 → 本卡 → 本地提交 → 停服务。
- **交付物**：新增 `examples/gateway_client_demo.py`（约 900 行，含内嵌世界）+ 新增 `tests/test_caller_demo.py`（20 例）；`README.md` 的 "Caller routes (§5.9)" 尾部加一段指向它；规格 §5.9 加"调用方样例"一行 + **新增 Q84**。**前端源码与 gateway 零改动** —— 本轮没有任何行为修改，样例只是既有 §5.9/§5.13 契约的读者。
- **按 §5.9 逐条覆盖 11 个接口**（14 步巡回）：`/api/health` → `/api/runtimeConfig` → `/events` → `/getWorld`（预检）→ `/updateWorld` → `/getWorld`（回读 id 清单）→ `/addObject` → `/updateItem` → `/get2DAABB` → `/captureScene` → `/updateTraj` → `/removeObject` → **§5.13 错误族 8 例** → 恢复上一份世界。**前两步的顺序本身是契约**（健康与能力判定必须先于写入，否则分不清"gateway 没起"和"没有浏览器"），`tests/test_caller_demo.py` 用 `assertLess(index of /api/health, index of /updateWorld)` 钉住。
- **分发口径（Q84 的核心决定）**：**① 只用标准库** —— 10 条 HTTP 走 `urllib.request`，唯一可选依赖是 `/events` 的 `aiohttp`，缺失时该步降级为一次跳过打印而不是崩；**② 绝不发 `browser.hello`**（见**坑 48**）—— 调用方监听器只收广播，一旦 hello 就被 `_register_browser` 认成浏览器、抢走 relay 给它的写入请求，真实浏览器再也收不到 ⇒ 全线 504；**③ 样例世界内嵌**（`SAMPLE_SCENE` 是从真实 OLS scene 6 生成的 `pprint` 字面量，用 `ast.literal_eval` 往返相等钉住"嵌入的就是那份文件"，全仓 grep 断言 `open(`/`read_text`/`Path(`/`data/scenes` 一个都不出现）；**④ 预检** —— 第 4 步 `/getWorld` 若 `503 NO_BROWSER_CONNECTED` 就抛 `NoViewerConnected`，打印"去开一个 tab"的操作说明并以退出码 2 结束，而不是让后面 10 步各报一次 503；回读若 `X-World-Source: cache` 则**禁用恢复**（缓存里的世界不是场上那份，写回去是破坏）。
- **`/updateTraj` 的样例字节**：30 fps / 90 帧 / 3 条记录（机械臂两段 `(0,40,…,0.6,0.7)` + `(40,50,…,0.7)`、杯子无段、**故意留一条不存在的 id 99** 好让响应体的 `ignored_objects` 非空）/ 2 条 attach（50 帧挂臂、80 帧挂桌），共 **2736 字节**，`pose_dim=7`、父级哨兵 `0xFFFFFFFF`；7 号槽位按 `drivers.ts:149` 的既有事实**只记录不驱动**（O1），注释里写明"这一路不会让几何动"。字节在测试里逐字段解析回来核 `attach_offset`、段偏移单调、data 区长度、缓动 0.0→0.6→0.0、未命令的关节等于世界里的 `initial_joint_positions_rad`。
- **本轮新学到的调用方侧事实（坑 47）**：`/addObject` 在 `MetadataRef` 网格**还没建好**时就返回 `ok:true`，紧接着 `/get2DAABB` 实测 `400 EMPTY_AABB`；样例因此提供 `get_aabb(..., attempts=10, delay=0.5)` 的重试读法并注明"异步资产加载是设计如此，调用方要自己等"。

- **验证**（一次性栈：gateway 8099 + OLS 8000 + vite 5188 + 一个 playwright tab，经仓库外 `scene5probe\run_demo.cjs` 编排）：**真机 14 步全过、退出码 0、页面零报错** —— `updateWorld` ⇒ `scene_version 4 / object_count 12 / rejected_objects []`；`addObject` ⇒ id **12**、v5；`updateItem` ⇒ v6、13 物体；`get2DAABB`（重试 2 次后）⇒ `visible true`、box `332.52/246.72/381.40/295.12` px、`aabb_world [0.4737,-0.1963,0.6639]→[0.6268,-0.0433,0.7708]`；`captureScene` ⇒ 640×480 PNG **91937 B**（magic `89504e47`）+ 深度 **1228800 B**（`640×480×4`）、中心 **1.500 m**、`217354/307200` 个 `NaN`；`updateTraj` ⇒ `{fps 30, total_frames 90, duration_seconds 3, object_count 3, attach_count 2, ignored_objects:[{99, OBJECT_NOT_IN_SCENE}]}` 且 `scene_version` **仍是 6**、**无 `scene.applied` 广播**（Q33 口径）；`removeObject` ⇒ `[12]`、v7；8 条错误码逐条与 `BROWSER_ERROR_STATUS` 预测一致；恢复 ⇒ v8、0 物体；全程 **4 条广播**、每条带 `source_browser_id`。回归链：`python -m unittest discover -s tests` **102 → 122 例 OK**、`audit_parity.py` **52 PASS / gaps []**、`tsc --noEmit` 0 错、vitest **327 例 / 14 文件**全绿（前端零改动 ⇒ 无新增单测）、`npm run build` ✓ 5.14 s；`docs/parity-probes.json` 只剩 `generatedAt`/`uptimeSeconds` 抖动，按口径 `git checkout --` 丢弃。
