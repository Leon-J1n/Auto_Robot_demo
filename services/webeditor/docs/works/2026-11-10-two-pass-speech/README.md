# 2026-11-10 流式预览与句末二次识别

## 原因
用户反馈轻量流式模型准确率不足，要求升级模型并在句末重新识别音频。

## 做了什么
独立语音服务升级中文 Zipformer，并加入 Paraformer 整句复核。同段文本替换预览，停止或发送等待复核后 done。前端收尾上限改为 60 秒，连接超时不变；沿用 §7.6 协议与发送逻辑，不增加 Gateway 路由、配置字段或依赖。

## 验证
前端 705/24 全套测试、TypeScript 检查与构建通过，JS 906.90 kB（仅修改同等长度超时常量，不增加运行时代码）。语音专项 10 项通过；负控制将 60 秒恢复为 10 秒，仅等待测试失败，之后按原始字节恢复。独立服务 7 项测试通过，复核替换负控制命中预期断言；真实 CPU/CUDA 两模型均解码成功，auto 实际为 cuda。真实 Gateway + 两模型经临时端口链路通过。未改网关实现、路由或共享配置，不运行已知会挂起的全量 parity 探针。尚无真实指令集准确率数据，不能宣称准确率必然提升。
