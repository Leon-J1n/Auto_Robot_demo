# 2026-11-09 语音输入状态与发送收尾

## 原因
用户要求明确显示正在语音输入的状态，点击发送或回车发送时停止识别。

## 做了什么
就地修订规格 §7.5/§7.6。将既有 Web Speech 回调移入可测试的 speech.ts，复用 mergeSpeech 及现有发送入口。聆听时麦克风玫红背景、白色加粗图标、高亮框与 aria-pressed；停止、结束、报错均复位。公共 submit 入口先停止再发送，清除旧回调并校验实例身份，防止停止后的延迟结果把输入框填回。保留发送瞬间可见文本。无新增依赖、功能键、协议、网关修改；不改现有 Shift+Enter/输入法规则，不更换语音引擎。

## 验证
11 项专项测试覆盖手动开关、自然结束、识别错误、启动失败、点击发送、输入框回车、麦克风焦点回车、非识别态回车及延迟旧结果。补充修复麦克风按钮焦点导致回车触发按钮默认点击的问题：切换后焦点回输入框，麦克风仍持焦点时回车也进入发送链。负控制分别撤销公共入口停止调用、实例身份保护，确认对应测试失败后逐字节恢复。完整前端 686 项/23 文件、类型检查及生产构建通过；JS 900.21→901.02 kB，CSS 21.85→22.07 kB。dist 为忽略产物，已本地刷新。麦克风引擎以测试替身验证，未在真实设备录音；坑清单补 126。
