## 任务卡原文

#### M6-2 资产面板（OLS 化）
- **规格**：§4.6、§6
- **涉及**：`main.ts:refreshAssets`(205)、`renderAssets`(290)、`app.addEventListener("click")`(654)
- **改动要点**：改为三个分组 **预设场景 / 预制模型 / 机械臂**，数据源 `GET {OLS}/list?type=scene|model|robot`（经 `library.ts`，直连 `library_server_url`；代理形式已按 **Q68** 退役）；列表项显示 `id + name`，并按 `category`（`list[].category` 点分层，配合 `GET {OLS}/listCategory?type=` 做分组/折叠，缺失即未分类）归类，支持本地名称过滤与刷新按钮；每张卡片用 `thumbnailUrl(kind,id)` 出 `<img src>`，403/404/CORS 失败降级为占位图且不得影响卡片可点。预设场景点击 = 清空 + 加载 + `browser.state_sync`；预制模型与机械臂点击 = 本地执行与 `addObject` 相同的逻辑（原点、`parent=null`、含 `MetadataRef`，机械臂走 `type=robot` 的 `/file` 且**不能**由世界文件引用（此句已由 **Q51** 修订：引用形式定为 `$LIBRARY_SERVER/robot?id=<n>`，裸数字仍恒为 `model` id）；**删除**上传、删除资产、builtin/project/uploaded 分组、依赖弹窗。
- **DoD**：§12.7（含三组列表、类别分组、缩略图降级）；OLS stub 关闭时面板显示错误提示且不影响当前场景。
- **验证**：手测 + `browser_smoke.cjs`（M7）。
- **已完成（2026-10-10）**：三组列表按 `library.ts` 的 `list/listCategories/thumbnailUrl` 落地，卡片显示 `name` + `id · category`；新增纯函数模块 `assets.ts`（`LIBRARY_KINDS`/`GROUP_LABELS`/`groupAssets`/`filterAssets`/`objectForItem`，决议 **Q51** 的第③点：UI 层不可测，所以"原点 + `parent=null` + 带类型的 `MetadataRef`"必须在纯模块里断言）；折叠走 `state.library.collapsed`（`<kind>:<category>` 键，`aria-expanded` + `.asset-cards[hidden]`），过滤走 `state.library.filter` 且只重写 `#asset-groups`；缩略图降级用容器上的**捕获阶段** `error` 监听（决议 **Q52**：图片 `error` 不冒泡，内联 `onerror` 是注入面，先探测会把 10 张卡变成 10 个额外请求）。**卡片原文有两处按实现修正**：① "机械臂……**不能**由世界文件引用"已被 **Q51** 推翻 —— 面板写入的就是世界文件，引用形式定为 `$LIBRARY_SERVER/robot?id=<n>`（`resolveMetadataRef` 相应改为返回 `{kind,id}` 的 `resolveMetadataTarget`）；② 连带 renderer 的 `models/robots/templates` 三张缓存必须按 `<kind>:<id>` 键（**Q53**），否则夹具里 `model?id=1` 与 `robot?id=0` 这两份同名 ur5e 会互吃 mesh。刷新按钮另暴露并修掉一个缓存缺陷（**Q54**/**坑 23**）：`LibraryClient` 把失败的 promise 也永久缓存，导致刷新一条请求都不发、OLS 重启后面板永久停在告警态，现改为"只缓存成功 + 刷新时 `invalidateMetadata()`"。`features.json` 补 `navigation.assets.{presets,prefabs,robots,refresh}` 四键（缺键即被隐藏，且**改完必须重启 gateway**，**坑 22**）；`styles.css` 删 `.upload`/`.asset-row`/`.modal-backdrop`/`.dependency-dialog`（含 767px 断点里的两处）换 `.asset-*` 一组；`legacy-types.ts` 删失去生产者的 `AssetSummary`。测试与真机数字见 §9 M6-2 行。
