## 任务卡原文

#### M5-1 `GET /captureScene`
- **规格**：§4.4、§5.10、§5.13
- **涉及**：`renderer.ts:renderSensorFrame`(843)（改为可离屏一次性价调用）、`local_gateway.py`（新 handler）、`main.ts`（`browser.request` 的 `captureScene` 分支）
- **改动要点**：请求 `type` 必须等于实体 `Camera.type`（否则 `400 CAMERA_TYPE_MISMATCH`）；尺寸/内参取 `Camera` 组件（`fov` **度** → `THREE.PerspectiveCamera.fov` 直接用，§2.6）；**排除一切辅助图层**（包围盒 overlay、选中描边、collider 线框、加载标记、gizmo）；深度 = `width*height*4` 小端 `float32` 米制、行主序、首行为顶行、未命中/超 `far` 为 `NaN`；响应为 §5.10 的 JSON+base64；`browser_id` 可选定向。
- **DoD**：`python -c` 脚本 base64 解码深度后 `np.frombuffer(dtype='<f4')`，中心像素距离与 `aabb_world` 中心同数量级（误差<5%，§12.5）；`type` 不匹配返回 400；无浏览器 503。
- **验证**：`python -X utf8 -m unittest tests.test_capture -v`（新建）。
- **已完成（2026-10-09）**：新增 `editor/src/capture.ts`（`applyCaptureRequest(world, request, view)` + `bytesToBase64`/`float32ToBase64`/`pngBase64`，§5.10 载荷装配与 §5.13 错误码全表在纯模块里可测）；`renderer.ts` 的 `renderSensorFrame` 重写为 `sensorSetup/sensorPass/colorTarget/colorPixels` 三段并新增 `renderSensorDepth(objectId): SensorDepthFrame | null`（`sensorMeters` 材质把 `viewDepth` 米数直写 `FloatType` 颜色附件、`EXT_color_buffer_float` 缺失即拒绝出图，决议 **Q44**），导出 `SensorLimits`/`NATIVE_SENSOR`（捕获不可覆盖尺寸，预览保留 640×480 上限）；`local_gateway.py` 新增 `capture_scene()` 与 `add_get("/captureScene", ...)`（注册紧跟 `/getWorld`、在通配 static 之前，门槛顺序见 **Q45**）；`main.ts` 新增 `captureCanvas` + `captureView`，`answerBrowserRequest()` 对 `captureScene` 走专用分支（"捕获读的是场景图，不只是世界"），`scene_requests.ts` 的 `idOf` 改为导出以复用同一套 uint 校验。`frame_index` 语义见 **Q43**。测试：新建 `tests/test_capture.py` **15 例**、`editor/src/capture.test.ts` **11 例**、`renderer.test.ts` +3 = **26 例**。验证与真机数字见 §9 M5-1 行（含 **坑 18**：base64 逐字符编码 315 ms → 分块 `btoa` 41 ms，是 §11.5 的 250 ms 预算的胜负手）。
