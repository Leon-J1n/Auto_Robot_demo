- **起因（用户原话）**：「下面进行下一项工作：优化Agent面板中的对话表现。要求命令和Agent回复采用聊天气泡的形式，命令靠右侧，Agent回复靠左侧。要能够明确区分出哪一条是用户发的命令，哪一条是Agent的回复」。决议记 **§13.37（Q120）**，正文**新增 §7.4**（八条口径）与**新增验收 §12.21**（四层判据 + 三条测量口径），README 的 Agent 面板那一段补一句。**本卡不推翻任何既有口径**，但**就地收紧两处**（历史留在本行，正文按新口径写）：§12.21 ② 的"用户左缘 > Agent 右缘"补上**前提"宽度不到半栏的那一对"**（两条都撑到 `max-width:86%` 时左右缘必然交叠，只有中心分边仍然成立），§7.4/§12.21 里"空态靠默认 `align-items:stretch`"改成实测口径（计算值是 `align-items: normal` + `align-self: auto`，两者合起来才按 stretch 用）。
- **一句话的落点**：**改动面只有 `editor/src/styles.css` 三处** —— `.agent-messages` 加 `display:flex;flex-direction:column`；`.message` 换成 `max-width:86%` + 四周 `1rem` 框 + `overflow-wrap:anywhere`；`.message.agent` = `align-self:flex-start` + 左缘 2rem 绿框 + 圆角 `2rem 10rem 10rem 10rem`，`.message.user` = `align-self:flex-end` + 右缘 2rem 蓝框（`var(--blue)`）+ 底 `#16283c` + 圆角 `10rem 10rem 2rem 10rem`，再加一条 `.message.user header { flex-direction:row-reverse }`。**`main.ts:agentMessageMarkup()` 一个字没改**：它本来就输出 `<article class="message user|agent">`，角色名与时间在 `<header>`、徽标在 `<footer>` —— "谁说的"早就在 DOM 里，本轮只是把它画出来。`result_view.ts`、`logic.ts`、两份 `types.ts`、`config/constant_config.json`、`features.json`、gateway 全部不动 ⇒ 这就是 §12.21 ① 那句"单测数量逐位不变"的物理原因，不是巧合。
