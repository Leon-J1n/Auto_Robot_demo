## 任务卡原文

#### M5-2 `GET /get2DAABB`
- **规格**：§4.5、§5.11
- **涉及**：`renderer.ts:frame`(743, `Box3`) 抽出一个纯函数 `worldAabb(objectId)`、新增 `projectBox()` 纯函数、`local_gateway.py` handler、`main.ts` 分支
- **改动要点**：世界 AABB（含父链与当前播放帧位姿）→ 8 角点投影裁剪空间 → 丢弃 `w<=0` → 像素矩形 → 与图像边界求交；输出 `coordinate_origin:"top_left"`、`visible`、`clipped`、`box{x_min,y_min,x_max,y_max}`、`aabb_world`；**全出画返回 200 + `visible:false` + `box:null`**；无可渲染几何 → `400 EMPTY_AABB`；**不做遮挡剔除**（Q4 决议）。投影函数放 `logic.ts` 以便单测。
- **DoD**：`logic.test.ts` 数值断言角点投影（含"身后 → 无角点"“边缘裁剪”）；curl 手测三态（完整可见/部分出画/完全不可见）。
- **验证**：`npx vitest run editor/src/logic.test.ts` + `python -X utf8 -m unittest tests.test_bbox -v`。
- **已完成（2026-10-09）**：新增 `logic.ts:projectBox(corners, viewProjection, width, height)` 纯函数（§5.11 的 `w<=0` 丢弃、NDC→左上像素、与图像边界求交、零面积算不可见四件事全在这里，决议 **Q46**）；`renderer.ts` 抽出 `worldAabb(objectId)`（`Box3.setFromObject`，含父链与当前播放帧位姿）并新增 `projectObjectBox(objectId, cameraId): SensorBoxFrame | null`（复用 `sensorSetup(cameraId, NATIVE_SENSOR)` 使尺寸与 `/captureScene` 逐像素一致，`toSceneBox()` 把 three 的 Y-up 盒换回世界文件的 Z-up 帧，决议 **Q47**）；`capture.ts` 新增 `applyAabbRequest(world, request, view)`（`camera_id` 校验 + `OBJECT_NOT_FOUND`/`CAMERA_NOT_FOUND`/`EMPTY_AABB` 码表）与 `CaptureView.box()` 查询；`main.ts` 的分派改为 `captureScene`/`get2DAABB` 两条专用分支（注释点明"这两条读场景图，不只是世界"），`reply()` 的泛型联合加入 `Get2DAabbResult`；`local_gateway.py` 新增 `get_2d_aabb()` + `add_get("/get2DAABB", ...)`（紧跟 `/captureScene`、在通配 static 之前，门槛只卡两个 uint id，响应只验 `visible` 是 bool，走 `capture_timeout_seconds`）。**与卡片原写不同的落点**：卡片只列了 `renderer.ts`/`logic.ts`/gateway/`main.ts`，实际多了 `capture.ts` 的 `applyAabbRequest` —— 理由是 §5.11 的三条 4xx 必须能在无 WebGL 的纯模块里逐条断言，与 M5-1 的 `applyCaptureRequest` 同构，两条只读路由共用 `CaptureView` 注入面。测试：新建 `tests/test_bbox.py` **16 例**、`editor/src/logic.test.ts` +7 = **19 例**、`capture.test.ts` +6 = **17 例**、`renderer.test.ts` +5 = **31 例**。验证与真机三态/互校数字见 §9 M5-2 行（含 **坑 19**：透视测试矩阵 `m[15]` 必须为 0；"相机量不出 AABB"是假前提）。
