## streaming-speech：独立语音服务

在 streaming-speech 项目目录打开 PowerShell，首次安装和模型下载：

```powershell
py -3.11 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe download_model.py
```

以上依赖用于 CPU 环境；NVIDIA 机器按语音项目 README 安装 requirements-gpu.txt 中匹配的 GPU 依赖，无需安装 PyTorch。已经配置好的 GPU 环境不必重装 CPU 依赖。

每次启动选择其中一种方式：

```powershell
./start.ps1
./start.bat
```

默认监听 `127.0.0.1:8600`。BAT 读取该项目 config.json 的端口，可用 `./start.bat --port 8601` 覆盖；PowerShell 脚本默认传入 8600，可用 `./start.ps1 -Port 8601` 覆盖，其余设置读取 config.json。Gateway 的 `config/constant_config.json` 中 `speech_service_url` 必须同步指向实际地址，默认 `http://127.0.0.1:8600`。修改 Gateway 配置后重启 Gateway。部署到不同主机时，还需将语音项目 config.json 的 host 改为可被 Gateway 访问的监听地址。

健康检查：`Invoke-RestMethod http://127.0.0.1:8600/health`，provider 表示实际 CPU/CUDA，two_pass=true 表示启用句末复核。浏览器经 Gateway `/speech` 转发到语音服务 `/stream`；远程浏览器不需要直接访问语音端口，麦克风访问仍需 HTTPS 或可信来源。

自行维护词表：修改语音项目 vocabulary.json 后重启语音服务；热词和型号别名的区别、添加示例及校验方法见该项目 VOCABULARY.md。模型与语音服务需单独部署，不随 WebEditor 打包。
