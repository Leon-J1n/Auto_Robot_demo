Windows PowerShell 原生启动（推荐使用仓库脚本）：

```powershell
F:\web-frontend\tools\restart_stack.ps1       # 清理并备份运行态后重启四服务
F:\web-frontend\tools\restart_stack.ps1 -KeepState
F:\web-frontend\tools\restart_stack.ps1 -Build
```

脚本会以 Hidden 窗口启动服务，日志写入 `F:\web-frontend\var\stack\*.out.log` 和
`*.err.log`，并在清理状态前将状态移动到带时间戳的备份目录。

手动启动命令（每个命令在独立 PowerShell 窗口执行）：

| 服务 | 命令 |
| --- | --- |
| QwenMock | `cd F:\QwenMock; F:\robot_agent_brain\.venv\Scripts\python.exe qwen_mock.py --port 8080 --model qwen-mock` |
| OLS | `cd F:\ObjectLibraryServer; F:\robot_agent_brain\.venv\Scripts\python.exe server.py --port 8000` |
| AgentBrain | `cd F:\robot_agent_brain\robot_agent_brain; F:\robot_agent_brain\.venv\Scripts\python.exe -m robot_agent_brain serve --config config\webeditor_local.json --gateway-url http://127.0.0.1:8099 --ols-url http://127.0.0.1:8000 --joint-inventory var\webeditor\joint_inventory.json --camera-id 5 --port 8500` |
| Web-gateway | `cd F:\web-frontend; F:\robot_agent_brain\.venv\Scripts\python.exe local_gateway.py --host 0.0.0.0 --port 8099` |



环境变量（主要是每个服务代码在哪个文件夹）：

$OLS_ROOT=F:\ObjectLibraryServer
$QWEN_MOCK_ROOT=F:\QwenMock
$ROBOT_BRAIN_ROOT=F:\robot_agent_brain\robot_agent_brain
$WEB_FRONTEND_ROOT=F:\web-frontend
