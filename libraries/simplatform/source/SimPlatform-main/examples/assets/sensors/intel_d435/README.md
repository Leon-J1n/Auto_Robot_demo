# Intel RealSense D435 approximate model

This dependency-free URDF approximates the D435 enclosure and front optics with
URDF primitives. Its nominal body size is 90 x 25 x 25 mm. It is intended as a
visual mounting reference for camera-sensor tests, not as a metrology-grade CAD
model. The local `+X` direction points out through the lenses and matches the
RobotSimPlatform camera optical-axis convention.

The model contains no Intel mesh or texture assets. `Intel` and `RealSense` are
identifiers for the represented product; this approximation is not provided or
endorsed by Intel.
