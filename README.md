# Auto Robot Demo

本项目用于机器人原子技能的开发、组合、测试与仿真演示。

## 目录说明

| 目录 | 作用 |
| --- | --- |
| `skills/` | 存储底层原子技能，包含运动、操作和感知等类型的技能实现、配置、参数校验及执行策略。 |
| `tests/` | 用于测试原子技能及相关配置，验证技能接口和执行结果是否符合预期。 |
| `demo/` | 用于测试和演示封装好的技能，包括场景配置、技能指令、运行入口及运行时逻辑。 |
| `control/` | 存储机器人及末端执行器的控制逻辑，如夹爪、按压和推拉控制器。 |
| `collision/` | 存储碰撞检测相关功能，用于判断机器人运动过程中的碰撞风险。 |
| `kinematics/` | 存储机器人运动学计算功能，包括正运动学、逆运动学等能力。 |
| `planing/` | 存储运动规划与轨迹生成逻辑，包括线性路径、轨迹和时间参数化功能。目录名沿用项目现有拼写。 |
| `world_model/` | 存储仿真世界模型、机器人模型、场景文件、物体资源及场景查看工具。 |
| `libraries/` | 存储项目依赖的第三方或本地算法库，例如 IKFast、TRAC-IK 等逆运动学库。 |
| `utils/` | 存储跨模块复用的通用工具，例如仿真运行时辅助功能。 |
| `hardware/` | 预留给真实机器人、传感器和其他硬件设备的接口与适配代码。 |

## 开发环境目录

| 目录 | 作用 |
| --- | --- |
| `.venv/` | Python 虚拟环境及项目依赖的本地安装目录。 |
| `.idea/` | JetBrains 系列 IDE 的项目配置目录。 |
| `.git/` | Git 版本控制数据目录。 |
